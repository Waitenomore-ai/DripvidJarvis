# Jarvis Improvement Research

Research brief: apps and add-ons for the Jarvis system that would improve
the family's day-to-day life. Topics of interest, in no particular order:

- Calendar sync: family calendar integration so Jarvis can track
  birthdays, school runs, and events.
- Alexa connection: link Jarvis to Alexa for hands-free/home commands.
- Home automation: lights, cameras, and other smart-home devices that
  Jarvis could integrate with or recommend.
- Anything else that makes the household run smoother.

## Deliverable

Write up the findings as a set of vault notes (one per topic, plus a
summary/recommendations note) describing what to adopt, what it would take
to set up, and which options are free/self-hosted when possible.

## Constraints

- Prefer free, self-hosted, or local-first options over paid cloud
  subscriptions when the quality is comparable.
- Prefer options that run on the existing Debian server where practical.
- Keep suggestions realistic for a family with children aged 6 to 25.
